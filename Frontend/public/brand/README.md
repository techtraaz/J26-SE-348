# Sri Lanka Air Force images

Drop images into this folder using **exactly** these file names (PNG).
The website picks them up automatically, with no code changes. When a file is
missing, the site shows the drawn version instead.

| File name                | Where it appears                                   | Suggested size          |
|--------------------------|----------------------------------------------------|-------------------------|
| `slaf-crest.png`         | Logo in the header (left), faint watermark on the sidebar and page | 512 × 512, transparent background |
| `sri-lanka-flag.png`     | Right side of the header (fades in from the left)  | 600 × 200               |
| `header-jet.png`         | Jet in the header                                  | 600 × 250, transparent  |
| `header-background.png`  | The WHOLE header strip (replaces jet + flag + gradient) | 1920 × 84           |
| `sidebar-background.png` | The WHOLE left sidebar background                  | 288 × 1080              |
| `page-background.png`    | The WHOLE chat / library background (sky, jets, mountains, crest) | 1920 × 1080 |
| `jet.png`                | The two jets in the page background (used if there is no `page-background.png`) | 800 × 330, transparent |

Tips
- Crop backgrounds from the design image **without** text, buttons or chat
  boxes on them; the site draws those on top.
- Transparent PNGs work best for the crest, flag and jets.
